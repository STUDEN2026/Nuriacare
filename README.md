# NURIA Care
Sistema de gestión y valoración de pacientes (proyecto académico, Informática 1, Universidad Hispanoamericana de Panamá). Todos los datos son ficticios.

## Ejecutar localmente
Abra `index.html` en un navegador. No requiere servidor. En **Configuración** pulse *Cargar datos de demostración*.

## Publicar en GitHub Pages
1. Cree un repositorio y suba el contenido de esta carpeta.
2. En *Settings → Pages* elija la rama `main` y la carpeta `/ (root)`.
3. Abra la URL que GitHub indique.

Los registros se guardan en el `localStorage` del navegador.
